# Онлайн Чат

Это проект для создания онлайн-чата с возможностью внедрения различных фич, включая использование Socket.io для реализации реального времени, добавление новых функций и улучшений.

## Описание

Данный репозиторий представляет собой основу для онлайн-чата, который будет расширяться функциональностью по мере необходимости. Начальный функционал включает чат с использованием Socket.io, а также возможность легко интегрировать новые фичи и улучшения.

### Текущие функции:
- **Реальный чат**: Сообщения передаются в реальном времени между пользователями с использованием Socket.io.
- **Подключение нескольких пользователей**: Пользователи могут присоединяться к чату и обмениваться сообщениями.
